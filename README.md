# GameStore API

A REST API for managing a collection of video games.

## Technologies
- C#
- ASP.NET Core
- .NET 10
- REACT

## Features
- Retrieve all games
- Retrieve a game by ID
- Create a game
- Update a game
- Delete a game
- Change a game
